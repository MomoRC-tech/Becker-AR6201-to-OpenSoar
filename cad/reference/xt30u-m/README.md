# AMASS XT30U-M (male, solder cups)

Unmodified third-party STEP model of the AMASS XT30U-M male connector with solder cups, from the KiCad library of **MuratovAS** (`MAS_3DModel/xt30u-m.step`). Created in FreeCAD, export 2024-04-09.

- Open [`xt30u-m.step`](xt30u-m.step) in CAD software.
- Downloaded from [MuratovAS/KiCadLibrary @ ba6956a](https://github.com/MuratovAS/KiCadLibrary/blob/ba6956a3ba9bc0938dced1b2eb1ae00a33c9a255/MAS_3DModel/xt30u-m.step).
- Model axes: X = 5.25 mm side, Y = 10.25 mm side, Z = length; solder cups at the +Z end.
- Dimensions and suitability: [housing](../../../docs/hardware/housing.md#contents).
- Provenance, checks and hash: S51 in [sources](../../../docs/research/sources.md#source-register).
