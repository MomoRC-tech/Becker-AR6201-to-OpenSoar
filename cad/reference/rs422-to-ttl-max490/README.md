# RS422 TO TTL board (MAX490)

Simplified project model of the selected blue RS-422 board, built in Autodesk Fusion from the [supplied component-side photo](../../../docs/images/rs422-to-ttl-supplied.png) and the 50 × 27 mm board size (S34). Exported by the project owner as `MAX490 board - CLAUDE.step` and stored here unchanged under a shorter name.

- Open the [STEP model](rs422-to-ttl-max490.step) in CAD software.
- Dimensions and limits: [housing](../../../docs/hardware/housing.md#contents).
- Checks and STEP hash: S46 in [sources](../../../docs/research/sources.md#source-register).

Part positions are scaled from the photo, not taken from a manufacturer drawing. Use the model for preliminary layout only.
