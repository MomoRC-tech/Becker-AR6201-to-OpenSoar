# RS422 TO TTL board (MAX490)

Simplified project model of the selected blue RS-422 board, built in Autodesk Fusion from reference photos including the [supplied component-side photo](../../../docs/images/rs422-to-ttl-supplied.png) and the 50 × 27 mm board size (S34). Exported by the project owner as `MAX490 board - CHATGPT.step` and stored here unchanged under a shorter name.

- Open the [STEP model](rs422-to-ttl-max490.step) in CAD software.
- Dimensions and limits: [housing](../../../docs/hardware/housing.md#contents).
- Checks and STEP hash: S46 in [sources](../../../docs/research/sources.md#source-register).

Component positions and connector details are estimated from photos. Use the model for preliminary layout only.
