# Housing layout v4 (candidate)

Layout candidate with the RS-232 boards on the ESP32's USB clamp ([housing § 5.1](../../../docs/hardware/housing.md#layout)). Exported from the owner's Fusion document `Housing layout - compact v4`, 2026-11-12, as a restore point. The editable model is the Fusion document itself: restore earlier states from its version history; this STEP keeps the part positions.

| File | Use |
| --- | --- |
| `housing-layout-v4.step` | All parts as solids, for checking positions or other CAD tools |

- Units: millimetres. Layout frame: X along the housing length from the outside face of the connector wall, Y up from the floor top, Z across.
- Contains the reference models from [cad/reference](../../reference/) (ESP32, RS-232, XT30, DE-9, UBEC); their attribution and licence notes apply.
- Holder in this layout: [esp32-holder-v3](../esp32-holder-v3/README.md).
