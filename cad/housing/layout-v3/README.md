# Housing layout v3

Selected internal layout ([housing § 5](../../../docs/hardware/housing.md#layout)): every part placed as a separate component, ready for the housing body to be modelled around it. Exported from the owner's Fusion document `Housing layout - compact v3`, 2026-11-12, as a restore point. The editable model is the Fusion document itself: restore earlier states from its version history; this STEP keeps the part positions.

| File | Use |
| --- | --- |
| `housing-layout-v3.step` | All parts as solids, for checking positions or other CAD tools |

- Units: millimetres. Layout frame: X along the housing length from the outside face of the connector wall, Y up from the floor top, Z across.
- Contains the reference models from [cad/reference](../../reference/) (ESP32, RS-232, XT30, DE-9, UBEC); their attribution and licence notes apply.
- Holder in this layout: [esp32-holder-v2](../esp32-holder-v2/README.md).
