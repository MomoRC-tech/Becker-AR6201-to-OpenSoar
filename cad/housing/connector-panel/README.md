# Connector panel

Connector wall section with the DE-9, the XT30 and space for the F1 holder, built on the fit-test results in [housing § 2.3](../../../docs/hardware/housing.md#fit-test). Built in Autodesk Fusion through MCP, 2026-11-12, from the earlier front-plate coupon; these exports are the repository copies.

| File | Use |
| --- | --- |
| `connector-panel.3mf` | Print-ready mesh (high refinement) |
| `connector-panel.step` | Solid model for checking dimensions or re-slicing |

- Units: millimetres; Z is the print direction. Print flat, front face down, as placed, without supports; about 6.2 cm³.
- Panel 86 × 25 × 3.0 mm; Z = 0 is the outside face.

| Feature | Value |
| --- | --- |
| DE-9 flange recess | 31.6 × 13.2 × 1.0 deep, outside face |
| DE-9 rear-body cutout | 19.9 × 11.5 |
| DE-9 holes | Ø3.4 at 25.0 spacing |
| DE-9 nut pockets | 5.6 across flats, 1.0 deep in the inside face |
| XT30 pocket | 10.55 × 5.25 (= measured body), 0.9 × 1.1 chamfers at one end for clearance, 8.0 deep through the panel and an 18 × 13 × 5 collar; insert front first from the back, the markings stop at the collar, the front stands 0.5 proud; glue in |
| F1 | Right end (x 63–86) kept free for the 5 × 20 mm holder |
